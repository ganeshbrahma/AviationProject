# ✈️ AviationProject

**Migration from MySQL to Hadoop Ecosystem using Cloudera**

---

## 📌 Overview

This project demonstrates the migration of data from a traditional MySQL database to a Hadoop-based ecosystem utilizing Cloudera. It encompasses batch and stream processing layers, ETL processes, and data visualization components.

---

## 🛠️ Technologies Used

- **Databases**: MySQL, Hive, HBase
- **Big Data Tools**: Hadoop, Cloudera, HDFS
- **ETL Tools**: BCP, Sqoop
- **Processing Frameworks**: Apache Spark, Apache Flink
- **Visualization**: Tableau, Power BI
